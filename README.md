# Asymmetric-Crypto-Suite
Asymmetric-Crypto-SuiteA collection of Bash scripts utilizing OpenSSL to implement industry-standard asymmetric encryption and digital signatures. This project demonstrates the practical application of the CIA Triad in a Unix-based environment.🛠 FeaturesAsymmetric Encryption (RSA-2048): Securely encrypt and decrypt files using public/private key pairs to ensure Confidentiality.Batch Processing: Scripts designed to handle multiple files within a directory, automating security workflows for scalability.Time-Bound Digital Signatures: Implements SHA-256 hashing and RSA signing to ensure Integrity and Non-repudiation.Temporal Metadata: Appends a cryptographic timestamp to files before signing to prevent replay attacks.📁 FilesFilenameDescriptionbatch_encrypt.shUses a public key to encrypt all .txt files in the directory.batch_decrypt.shUses a private key to decrypt .enc files and recover original data.signature_timestamp.shAppends a timestamp and signs the file with a private key.verify_extract_timestamp.shVerifies the signature and extracts the signing time using a public key.🚀 Usage Instructions1. PreparationEnsure your keys are generated and the scripts have execution permissions:Bashchmod +x *.sh
2. Encryption/DecryptionTo encrypt your files:Bash./batch_encrypt.sh public_key.pem
To decrypt and recover your files:Bash./batch_decrypt.sh private_key.pem
3. Digital SignaturesTo sign a file with a time-bound signature:Bash./signature_timestamp.sh test1.txt private_key.pem
To verify the authenticity and check the time it was signed:Bash./verify_extract_timestamp.sh test1.txt.signed_tmp test1.txt.sig public_key.pem
🛡 Security AnalysisDuring testing, this suite successfully identified Integrity violations. If a single character within a signed file is modified, the verification script correctly flags the signature as invalid, demonstrating protection against man-in-the-middle (MitM) or unauthorized tampering.
